Проект <code>Dobriy Shkaf</code> представляет собой монорепозиторий и собранное
десктоп-приложение для операционных систем Windows и MacOS, созданное для социального проекта <code>Добрый Шкаф</code> НКО <code>Российский детский фонд</code> в рамках выполнения студенческого
социального заказа.
