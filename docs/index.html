Добрый Шкаф

Dobriy Shkaf Application

Проект Dobriy Shkaf Application представляет собой монорепозиторий и собранное десктоп приложение, созданное для некоммерческой организации "Добрый Шкаф" в рамках выполнения студенческого социального заказа.

Техническая документация

Монорепозиторий содержит настольный frontend на Kotlin и backend на Java/Spring. Модули живут отдельно и собираются через Gradle wrapper.

Frontend

Модуль frontend реализует Swing-приложение с MVI-подходом для удобной работы с данными.

Backend

Модуль backend предоставляет Spring REST API для получения, создания, обновления и удаления семей.

Требования

  • JDK 17.
  • Gradle wrapper из репозитория: gradlew или gradlew.bat.

Команды

Посмотреть все доступные Gradle-задачи:

./gradlew tasks --all

Запуск frontend:

./gradlew :frontend:run

Сборка frontend:

./gradlew :frontend:build

Сборка backend:

./gradlew :backend:build

Сборка всего проекта:

./gradlew build

REST API

Метод Путь Назначение
GET /api/families-admin/all Получить полный список семей.
GET /api/families-admin/{id} Получить одну семью по идентификатору.
POST /api/families-admin/create Создать новую карточку семьи.
POST /api/families-admin/update Полностью обновить существующую карточку.
POST /api/families-admin/delete/{id} Удалить карточку семьи.

Настройка адреса backend

По умолчанию frontend обращается к:

http://185.204.0.88:8082/api/families-admin

Адрес можно переопределить системным свойством:

./gradlew :frontend:run -Ddatabase.api.base=http://host:port/api/families-admin

Или переменной окружения:

DATABASE_API_BASE=http://host:port/api/families-admin ./gradlew :frontend:run

Работа с ветками

Основная интеграционная ветка: main. После завершения задачи изменения из frontend или backend объединяются в main через PR или merge.

Пользовательская документация

Приложение открывается как настольное окно "Отчёт город Спутник" и помогает вести карточки семей: просматривать список, создавать новые записи, редактировать данные и удалять неактуальные карточки.

Начало работы

  1. Запустите приложение командой ./gradlew :frontend:run или установив, а затем запустив Dobriy Shkaf.exe.
  2. Дождитесь загрузки списка семей в левой таблице.
  3. Выберите нужную строку, чтобы открыть карточку семьи справа.
Если список не загружается, проверьте наличие Интернета на персональном компьютере.

Основные кнопки

Кнопка Что делает
Обновить Загружает актуальный список семей.
Новая Очищает форму и переводит экран в режим создания новой карточки.
Сохранить Создает новую карточку или сохраняет изменения выбранной семьи.
Удалить Удаляет выбранную карточку после подтверждения.

Работа с таблицей

  • Список семей находится слева.
  • Выбор строки открывает карточку семьи в форме справа.
  • Таблица сортируется стандартными средствами JTable.
  • После сохранения или удаления список обновляется в интерфейсе.

Заполнение карточки семьи

В форме доступны контактные, социальные и учетные поля:

  • номер семьи, ФИО родителей, телефон, адрес;
  • информация о детях и социальные признаки;
  • даты визитов и обменов;
  • пожертвования, обмен, остаток и суммы баллов;
  • пожертвование в рублях, доплата, тип оплаты и количество взятых вещей.

Даты и раскрывающиеся блоки

  • Для дат используется встроенный календарь рядом с полем.
  • Кнопка очистки рядом с календарем сбрасывает дату.
  • Группы Дарение, Обмен и Остаток можно свернуть или раскрыть.

Сохранение изменений

  1. Выберите карточку в таблице или нажмите Новая.
  2. Заполните поля формы.
  3. Нажмите Сохранить.
  4. Проверьте строку статуса внизу окна: там отображаются загрузка, сохранение, ошибки и количество записей.
